# goutoujunshi-plus（狗头军师 升级版）

恋爱军师与情绪支持 skill：先接住情绪，再分清事实，最后给能执行的选择。覆盖心动、暧昧、约会、冲突、分手、复合、婚姻家庭等场景，附带知识库（`references/knowledge`）与实用话术指南（`references/practical`），支持经同意、可撤销的本地长期关系档案（`scripts/memory_store.py`）。

## 安装

```bash
git clone https://github.com/Empyrean123123/goutoujunshi-plus ~/.claude/skills/goutoujunshi
```

关系档案只保存在本机（macOS：`~/Library/Application Support/goutoujunshi`），不会写进本仓库。
